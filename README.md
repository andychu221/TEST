Stock Price Monitor (股市價格監控面板) 專案簡介

📖 專案概述

Stock Price Monitor 是一個輕量級、無後端的網頁端應用程式。專為需要每日追蹤關鍵科技股（如台積電、美股七雄 Mag7）、大盤指數及 ADR 溢價率的投資者與分析師所設計。

本系統不僅能自動抓取並整合跨國市場（台股、美股、韓股、歐股）的歷史與最新報價，更具備強大的自動對帳 (Reconcile) 與智慧列印 (Smart PDF Export) 功能，幫助使用者快速產出高準確度、適合列印的財務日報表。

✨ 核心功能 (Key Features)

1. 智慧報表生成 (Dynamic Data Table)

靈活的時間軸：根據使用者設定的「As of (基準日)」，自動計算並顯示最近 19 個交易日的連續數據，以及歷史關鍵節點（如過去 10 年的開盤首日、台積電除息日、特定紀念日）。

視覺化漲跌指標：自動計算單日漲跌幅，並使用符號（△、▽）標示。針對台股，當漲跌幅超過 9.8% 時會自動標示為漲跌停符號（▲、▼），並具備除息日專屬星號（☆）標示。

自訂公式運算：內建自動計算 ADR 溢價率（TSM vs 2330.TW 搭配即時匯率）以及美股七雄 (Mag7) 的等權重指數。

2. 官方資料自動核對 (Reconcile System)

多源備援機制：為了確保資料準確性，系統提供「Reconcile」對帳面板。它會自動抓取台灣證交所 (TWSE) 等官方即時資料來與系統現有數據比對。

智慧 Fallback (降級) 策略：當面臨嚴格的防爬蟲保護（如 Nasdaq/NYSE）或 CORS 限制時，系統會自動切換至 Yahoo Finance API 進行備援抓取，並明確標示資料來源。

狀態燈號與快捷連結：比對一致顯示綠色，不一致或抓取失敗顯示紅色，並附帶真實的官方網站連結，方便使用者點擊跳轉進行人工確認與手動修正。

3. 一鍵單頁匯出 (Smart Print to PDF)

動態自動縮放：解決了網頁表格列印時常被截斷或溢出到第二頁的痛點。點擊「Print / PDF」時，系統會自動計算表格的寬高比例，並將畫面完美縮放至剛好塞滿一張 A4 橫式頁面。

4. 彈性配置與即時互動 (Config & Interactivity)

即時編輯與防呆提醒：報表內所有數值均可手動點擊修改。當數值被手動更改時，背景會亮起「橘色」閃爍 5 秒，提醒使用者該數據已經過人工覆寫。

欄位自訂 (Config)：使用者可透過右上角設定按鈕，隨時修改股票代號、顯示名稱、備註、小數點位數以及註腳編號。

自適應縮放：提供直覺的放大 (+) 與縮小 (-) 按鈕，方便在不同解析度的螢幕上閱讀龐大的數據矩陣。

🛠 技術架構 (Tech Stack)

本專案採用純前端技術打造，強調部署的便利性與執行效率：

核心語言：HTML5, CSS3, Vanilla JavaScript (ES6+)。

資料來源：

主資料庫：從 GitHub Repository 讀取預先編譯好的 JSON 靜態檔案。

即時核對：透過 CORS Proxy (allorigins) 串接 TWSE API 與 Yahoo Finance Chart API。

無後端依賴：所有資料處理、均線運算、匯率換算與 UI 渲染皆在客戶端 (Browser) 完成。

🚀 適用場景 (Use Cases)

每日晨報製作：分析師可在每日開盤前，快速一鍵開啟頁面並輸出成 PDF 報表，發送給團隊或客戶。

跨市場套利觀察：透過台積電與 TSM 的溢價率、台幣匯率的同框顯示，快速判斷外資動向與套利空間。

歷史回測比對：隨意切換「As of Date」，即可宛如搭乘時光機，檢視過去任意時間點的市場全貌與特定歷史事件的影響。
